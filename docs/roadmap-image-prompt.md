# Roadmap Image Generator Prompt

Use this prompt to create a multimedia or infographic version of the Canvas Design Studio roadmap.

## Prompt

Create a clean, modern, professor-friendly visual roadmap for a product called "Canvas Design Studio." The visual should feel like an educational technology product roadmap, not a startup sales deck.

Format: wide 16:9 infographic suitable for a presentation slide or website hero section.

Visual structure:
- A horizontal journey from left to right with four major stages:
  1. Available Now
  2. Being Built Now
  3. Coming Next
  4. Future Ideas
- Use clear cards or timeline panels for each stage.
- Show the low-barrier beginner workflow as a prominent first signal: "Generate HTML -> Paste into Canvas."
- Show direct Canvas publishing as optional, not required.
- Include small icons or visual metaphors:
  - document/page for Canvas-safe HTML
  - checkmark/shield for validation and FERPA preflight
  - course list or dashboard for course picker
  - accessibility symbol for accessibility checks
  - paintbrush or layout grid for design critique
  - video play button for Panopto/video support
  - folder for assignment folder ingest
  - student group silhouettes for persona review
  - compass or notebook for teaching philosophy profile

Content to include:
- Title: "Canvas Design Studio Roadmap"
- Subtitle: "From Canvas-ready HTML to optional direct publishing"
- Available Now:
  - Canvas-safe page generation
  - Manual paste workflow
  - HTML validation
  - Institution styling
- Being Built Now:
  - Optional Canvas API setup
  - Course picker
  - Direct page publishing
  - FERPA preflight
  - Title collision protection
- Coming Next:
  - Accessibility checks
  - Design critique
  - Video support
  - Assignment folder ingest
- Future Ideas:
  - Student persona review
  - Teaching philosophy profile
  - Community assignment standard

Style:
- Professional university technology aesthetic.
- Calm, readable, and trustworthy.
- Use Boise State-inspired blue as the primary color, with neutral backgrounds and restrained orange accents.
- Avoid cartoon style, clutter, tiny text, dark gradients, and generic stock-photo feel.
- Use readable labels and simple icons.
- Make the roadmap understandable at a glance.

Composition:
- Clean white or light neutral background.
- Blue section headers.
- Orange accent line or progress markers.
- Plenty of whitespace.
- Include subtle Canvas/course-page UI shapes in the background, but keep them secondary.

Output quality:
- High-resolution, crisp vector-like infographic.
- Text must be spelled correctly and remain legible.
- No logos unless explicitly provided.
- No screenshots of real Canvas courses or student data.

## Animated / Multimedia Version

Create a short 20-30 second animated explainer storyboard for "Canvas Design Studio Roadmap." Use a clean university ed-tech visual style with Boise State-inspired blue, neutral backgrounds, restrained orange accents, crisp UI cards, and simple icons.

Storyboard:
1. Opening frame: title "Canvas Design Studio Roadmap" with subtitle "From Canvas-ready HTML to optional direct publishing."
2. Scene 1, Available Now: show a professor turning assignment notes into a polished Canvas page. Text: "Generate HTML -> Paste into Canvas." Emphasize "No API setup required."
3. Scene 2, Being Built Now: show optional Canvas connection, course picker, direct publishing, FERPA preflight, and title collision protection as connected cards.
4. Scene 3, Coming Next: show accessibility checks, design critique, video support, and assignment folder ingest.
5. Scene 4, Future Ideas: show student persona review, teaching philosophy profile, and community assignment standard.
6. Closing frame: "Feedback wanted from professors" with three question bubbles: "Is this easy to start?", "What should Canvas publishing warn about?", "Which accessibility checks matter most?"

Motion direction:
- Smooth left-to-right timeline movement.
- Cards slide in gently.
- Use subtle icon animations, not flashy effects.
- Keep all text large and readable.
- Avoid clutter, stock photos, real student data, real Canvas screenshots, or institutional logos unless provided.

Output should feel like a polished conference-slide animation or short product explainer for faculty, not a commercial advertisement.
